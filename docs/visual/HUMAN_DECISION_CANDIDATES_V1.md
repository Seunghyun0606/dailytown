# Daily Town — Human Design Decision Candidates v1

Status: **resolved for current MVP direction on 2026-08-26**. Retained as decision history and future comparison reference.

## Selected current-production bundle

- Best Friend ceiling: **BF-B Signature Explorer**
- Shipping companions: **SC-B Moru + Luca**
- Motion personality: **M-B Responsive Soft**
- Outdoor QA policy: **R-B Balanced**
- App identity direction: **ID-A Sprout Town Mark**

## 1. Best Friend transformation ceiling

### BF-A — Keepsake Only

Not selected for current direction.

### BF-B — Signature Explorer — SELECTED

Current shipping ceiling:

- patchwork scarf with a controlled readable edge
- one small pressed-leaf/thread motif near the sprout
- travel-worn bag/tag composition in large contexts
- compact map avatar removes most bag/accessory detail
- no anatomy or face changes

### BF-C — Evolved Character Variant — FUTURE TODO

Not part of the current shipping cosmetic system.

Future product/user decisions may activate BF-C to increase character variation. When activated, it must be modeled as a separately versioned character variant such as:

`companion.moru.variant.best_friend_01`

Reference: `docs/visual/BF_C_VARIANT_EXTENSION_TODO_V1.md`.

## 2. Shipping companion set

### SC-B — Moru + Luca — SELECTED

- Moru remains canonical first companion.
- Luca becomes the first non-Moru shipping companion.
- Beri remains preferred next expansion candidate.
- Pino requires another silhouette-separation review before shipping.

Reference: `docs/visual/LUCA_PRODUCTION_BRIEF_V1.md`.

## 3. Motion personality

### M-B — Responsive Soft — SELECTED

- subtle but visible idle breathe
- clear one-shot clue reaction
- happy/resolved use one readable anticipation/settle beat
- no exaggerated perpetual bounce
- map-avatar amplitude lower than encounter/result

Final timing/easing remains a human gate after visible prototype QA.

Reference: `docs/visual/MOTION_RESPONSIVE_SOFT_TARGET_V1.md`.

## 4. Outdoor readability acceptance

### R-B — Balanced — SELECTED

Critical semantic readability is still mandatory. Documented degradation of purely decorative atmosphere may pass when gameplay state, route, provider/legal UI and practical HUD readability remain clear.

Reference: `docs/visual/OUTDOOR_READABILITY_POLICY_RB_V1.md`.

## 5. App identity

### ID-A — Sprout Town Mark — SELECTED DIRECTION

The service mark is companion-independent and combines:

- two-leaf sprout
- subtle path/door/town cue
- compact geometric launcher silhouette

Artwork candidates to compare before final lock:

- ID-A1 Sprout + Path
- ID-A2 Sprout + Doorway
- ID-A3 Sprout + Town Tile

Reference: `docs/visual/APP_IDENTITY_ID_A_BRIEF_V1.md`.

1. final M-B motion timing/easing/intensity after actual prototype review
2. physical-device outdoor readability final acceptance under R-B
3. final ID-A icon/logo candidate lock after visual comparison
4. any future explicit decision to activate BF-C variants (post-MVP enhancement, not an MVP blocker)
