# DailyTown Final Design Review Showcase

This directory is a review-only entry point for the currently approved DailyTown visual work.

## What it shows

- Design Baseline v2
- Explore visual parity reference
- Companion / Records finish reference
- Moru Candidate 3 canonical + usage-context crops
- Old Ginkgo first-scenario asset family
- ID-A2 Sprout Gate
- M-B2 Calm Reactive motion preview
- R-B outdoor readability status

## Open locally

From the repository root:

```powershell
git fetch origin
git switch design/final-human-gates-v3
git pull
start "" "design\review\final-human-gates-v3\showcase\index.html"
```

macOS:

```bash
open design/review/final-human-gates-v3/showcase/index.html
```

Linux:

```bash
xdg-open design/review/final-human-gates-v3/showcase/index.html
```

No build step or web server is required; all references are repository-relative.

## Scope

This showcase does not create new art, mutate canonical Moru assets, activate Android runtime resources, or claim R-B physical-device PASS.
