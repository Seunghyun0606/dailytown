# Moru semantic authoring handoff v1

Status: **HANDOFF_READY / EXPRESSION + AFFINITY ART NOT YET PRODUCED**

This package does not create a new Moru design. The accepted neutral PNG/ORA remains the identity authority, and the accepted lighting family remains reusable.

## Authoring order

1. Keep the accepted neutral master immutable.
2. Author only five additional 1280×1600 LIGHT/base expression masters: happy, curious, surprised, clue_found, resolved. Neutral is reused.
3. Run identity + expression QA before any fan-out.
4. Author familiar/trusted/best_friend as restrained transparent keepsake overlays where possible; do not repaint anatomy.
5. Composite expression + affinity, then apply the already-PASS lighting transform.
6. Derive the six usage contexts from each accepted semantic master.
7. Run cross-family/mobile/fallback QA; only then prepare MORU-03.

## Important

The exact canonical crops under `source/` are visual guides only. They are intentionally too small to be production masters and must not be upscaled and mislabeled as native assets.
